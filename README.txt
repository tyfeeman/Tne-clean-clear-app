TNE Clean & Clear Business Hub — Version 1
This is a functional browser-based prototype/PWA foundation.
Open index.html in a modern browser. Data entered is saved locally in that browser.
Version 1 includes Dashboard, Jobs, Customers, Calendar, Estimates, Invoices, Employees placeholder, and Cleaning Checklists.
Next production phase: secure cloud database, user login, employee accounts, online payments, SMS/email notifications, file/photo uploads, recurring contracts, and deployment as an installable iPhone/Android app.
